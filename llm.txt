# human-native-knowledge-skills (hnk) — AI entry point

> STATUS: pre-v1 (M3: orchestrator and templates landed; scripts land at M4, guides at M5, examples at M6).
> This file is the single entry point for AI agents consuming this repository.

## What this repository is

A SKILL, not a template. You (the AI agent) read this repository by URL and
apply its context operating system to a target project. The goal you serve:
"the accumulation of knowledge that both humans and AI can easily understand."

## Consumption modes

| Mode           | When                                          | You read, in this order |
| -------------- | --------------------------------------------- | ----------------------- |
| install        | "apply this to my project"                    | core/philosophy.md, core/audit.md → skill/01..10 → orchestrator.md → templates/ (instantiate: resolve {{PLACEHOLDER}}s, resolve and remove ai-instruction comments, skip interview-gated optional files) → scripts/hnk.mjs (copy verbatim) |
| audit-existing | "map/audit my existing docs into this system" | same list as install; at orchestrator.md step 4 run the audit-existing variant — existing documents are bound by pointer mapping, never moved, and an existing docs/ becomes the Living layer |
| learn          | "explain this system"                         | core/philosophy.md, core/audit.md → skill/01..10 — nothing else |

Boundary rule: `examples/` is an INSTANCE DEMO of an installed target project.
It is NOT part of the spec. Never parse examples/ as rules.

## Fetch guidance

Fetch raw file contents (e.g. https://raw.githubusercontent.com/seongjaeryu/human-native-knowledge-skills/main/<path>),
not rendered HTML pages. After fetching a file, confirm it ends with an intact
final section (no truncation) before acting on it; refetch on mismatch.
